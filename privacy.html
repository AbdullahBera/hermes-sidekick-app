Privacy policy

Last updated: 24 November 2026

Hermes is a personal assistant used by a single person, its owner, on their own computer. This policy explains what it does with Google user data.

What data it accesses

Only with the owner's explicit consent, and only read-only access to the owner's own account:

  • Gmail (gmail.readonly): message senders, subjects, dates, snippets and text, to summarise and search the owner's email when they ask.
  • Google Calendar (calendar.readonly): event titles, times and locations, to answer questions about the owner's schedule.

Hermes cannot send, modify or delete email or calendar events.

How the data is used and stored

  • Data is fetched on request and processed by an AI model running on the owner's own computer.
  • It is not sold, shared with third parties, used for advertising, or used to train AI models.
  • The access token is stored only on the owner's computer, in an isolated environment.

Revoking access

The owner can revoke access at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Hermes's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
